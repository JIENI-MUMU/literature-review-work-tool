# 文献综述笔记

一个帮我练习读文献、评判文献、组织文献综述的小工具。纯网页，不需要安装，电脑和手机浏览器都能用。

**打开地址：** https://jieni-mumu.github.io/literature-review-work-tool/

## 它做什么

- **多个项目，共用一个文献库**：左边栏列出所有项目，点一下切换，右键改名或删除。文章的事实（方法、结果等）只记一次，所有项目共用；问题、评价、总结每个项目各写各的。

- **文献列表**：只显示 4 列（标题、年份、作者、全文已读），按问题筛选用上方的下拉框，一句话总结以小字显示在标题下面，一屏能看几十篇。没读完全文的行左侧有红线，提醒不能引用。
- **笔记卡**：点开一篇，左边是目录（基本信息 / 研究问题 / 研究方法 / 研究结果 / 讨论与结论 / 我的评价 / 引用与总结），顺序和论文章节一样，点哪项右边显示哪项。每个格子有灰色提示，旁边的“?”有说明和例子。
- **研究问题**：工作问题，可以随时改，每次修改自动留历史。
- **使用说明**：工作流、四类观点、六个陷阱、笔记怎么变成论文语言。
- **拖入 PDF 自动识别**：在 PDF 里找 DOI，自动填标题、作者、年份、期刊（用 Crossref，免费，不用 AI）。PDF 只在本机读取，不上传。也可以手填 DOI。
- **导入 Zotero CSV**、**导出 Excel / CSV / 完整备份**。
- **自动同步**：数据存在私有仓库 `literature-review-work-data`，打开自动拉取，修改后自动上传。

## 第一次使用

1. 打开上面的地址。
2. 先去“研究问题”写两三个工作问题。
3. 开启同步：打开“使用说明”第七节，按步骤生成令牌，填进“设置”页。**每台设备第一次都要填一次。**

## 隐私

- 这个仓库（软件代码）是公开的，里面**没有**你的任何笔记。
- 笔记只存在两个地方：你设备的浏览器里，和你的私有仓库 `literature-review-work-data` 里。
- 令牌只存在你设备的浏览器里。不要把令牌发给任何人。

## 想改点什么

| 想改 | 改哪个文件 |
|---|---|
| 格子的提示文字、例子 | `js/hints.js` |
| 使用说明页 | `js/guide.js` |
| 颜色、字体、排版 | `css/style.css` |
| 功能 | `js/app.js`（页面）、`js/store.js`（存储和同步） |

在 GitHub 网页上点开文件，点右上角的铅笔图标就能直接改，保存后一两分钟网站自动更新。

改功能之前，先读 `SPEC.md`，里面记录了所有设计决定和原因。让 Claude 帮忙改的时候，把 `SPEC.md` 给它看。

## 第三方组件

- PDF 读取使用 [PDF.js](https://mozilla.github.io/pdf.js/)（Apache 2.0），文件在 `vendor/`。
- Excel 导出使用 [SheetJS Community Edition](https://sheetjs.com/)（Apache 2.0），文件在 `vendor/`。
